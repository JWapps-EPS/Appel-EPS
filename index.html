Google Sheet comme base de données

Toutes les données (classes, appels, activités, suivi) sont lues et écrites dans ton Google Sheet via une petite passerelle Apps Script que tu déploies une fois. Voir le guide fourni à côté de ce fichier.

Bon à savoir

• Sans URL configurée, l'application fonctionne quand même, en local sur cet appareil.
• Si le Sheet est injoignable (pas de réseau), les dernières données synchronisées restent affichées et modifiables ; la synchronisation reprend automatiquement au prochain changement.
• Le jeton n'est qu'une protection basique : toute personne avec le lien de l'application web et le jeton peut lire/écrire les données.
