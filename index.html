Appel EPS

    À l'oral, dites les prénoms des présents (ou prénom + nom en cas d'homonyme). Mots-clés avant le prénom : « oubli Lucas » = matériel oublié, « inapte Léa » = inapte, « absent Tom » = absent. « Terminer l'appel » marque absents tous les élèves non cités.

    Classes

    Classe sélectionnée

    Élèves (0)

    Colonnes « Nom » et « Prénom », ou une seule colonne « NOM Prénom » (export Pronote). Les doublons sont ignorés.

    Périodes et activités

    Jusqu'à 2 APS par période. Si la période a 2 APS, indiquez le jour de chacune (ex : Badminton le lundi, Natation le jeudi) : l'APS est alors choisie automatiquement selon la date de l'appel.

    Connexion Google Sheet

    Sans connexion, l'appli fonctionne en local sur cet appareil. Une fois connectée, chaque modification est envoyée au Sheet (mise en file d'attente si pas de réseau).
